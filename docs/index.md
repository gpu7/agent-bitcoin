## What is Agent-Bitcoin?

Agent-Bitcoin provides a simple, secure way for autonomous AI agents to interact with the Lightning Network and Bitcoin.

### Key Features

- Simple SDK for creating and paying Lightning invoices
- Fixed 1,000 sat transaction fee model
- Split architecture (AWS backend + local counterparty nodes)
- Easy integration with LangChain, Ollama, Grok, CrewAI, etc.
- Full regtest environment with ready-to-use scripts
